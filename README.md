# 股票分析 · 咕噜推算

网页版股票分析软件，手机/电脑浏览器打开即用：https://maplejacky-dotcom.github.io/Stock-Analysis/

功能：
- 📊 K线 + MA20/MA50 + 成交量 + MACD + RSI
- 🔮 咕噜推算：趋势评分、关键支撑/阻力、看多/基准/看空三情景概率
- 💰 基本面：市值、PE、PB、EPS、营收、利润率、ROE、股息、52周区间、分析师目标价
- 📉 做空数据：FINRA 每日做空占比（20天趋势）
- ⚡ 期权大单：Put/Call 比、异动大单（CBOE，延迟15分钟）
- 👔 内幕交易：SEC Form 4 近90天高管/股东买卖

数据每日美东时间盘前自动更新（GitHub Actions）。新增覆盖代码：编辑 `tickers.txt` 后手动运行一次 workflow 即可。
